Before publishing:
1. Create your Lemon Squeezy Creator Crawler product.
2. Copy its checkout URL.
3. Open script.js.
4. Replace:
   const BUY_URL = "";
   with:
   const BUY_URL = "YOUR_CHECKOUT_URL";
5. Add your preferred support email/contact information to support.html.
6. Upload this entire folder to your web host.
